🚀 AI Resume Optimizer

Transform your resume into a job-winning machine using AI 🤖

⸻

✨ Overview

AI Resume Optimizer is an automation workflow built using n8n that helps users:
	•	📄 Upload their resume (PDF)
	•	🎯 Match it with a job description
	•	🤖 Automatically tailor the resume using AI
	•	📊 Generate an ATS score with improvement tips
	•	📬 Receive results via email

⸻

🔥 Features
	•	Resume parsing (PDF → text)
	•	AI-powered resume rewriting
	•	ATS score analysis (0–100)
	•	Missing keyword detection
	•	Improvement suggestions
	•	Email delivery system
	•	Fully automated workflow

⸻

🧠 Tech Stack
	•	n8n (Workflow Automation)
	•	Google Gemini / OpenAI
	•	Gmail API
	•	PDF Processing

⸻

🚀 How It Works
	1.	Upload resume + job description
	2.	AI rewrites and analyzes
	3.	Email with results is sent

⸻

⚙️ Setup
	1.	Import resume_builder.json into n8n
	2.	Add your API keys (Gemini/OpenAI)
	3.	Connect Gmail
	4.	Run workflow

⸻

⚠️ Note

This project does NOT include API keys.
You must add your own credentials.
